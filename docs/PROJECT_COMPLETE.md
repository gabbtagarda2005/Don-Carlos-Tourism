## ❓ EXPECTED QUESTIONS & QUICK ANSWERS

**Q: Why use MongoDB instead of SQL?**
A: Flexible document structure, horizontal scalability, faster prototyping for tourism data that varies in structure.

**Q: How secure is the system?**
A: JWT authentication, password hashing with bcryptjs, role-based access control, input validation, activity logging.

**Q: What if the server crashes?**
A: MongoDB Atlas automated backups, cloud hosting with 99.9% uptime SLA, monitoring tools in place.

**Q: Can businesses make money through this?**
A: Yes, increased visibility, direct customer contact, promotion tools, future booking & payment features.

**Q: How many users can it handle?**
A: Single server ~1000 concurrent, scalable to millions with load balancing and database sharding.

**Q: What's the cost to deploy?**
A: Very low - free tier options available for development, ~$10-50/month for small production deployment.
